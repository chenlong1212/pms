# PMS 1:1 可视化编辑器

编辑器直接挂载正式前端 `frontend/src/App.vue`，因此页面内容与当前开发版本保持一致，不再维护一份独立的模拟原型。

## 启动

编辑器会直接挂载正式前端源码，不需要另外启动 `5173`。如果要查看实时接口数据，请确保后端 `8080` 正常运行，然后执行：

```bash
cd /Users/guazi/Projects/pms/layout-prototype
node dev.mjs
```

打开：<http://127.0.0.1:4174/>

## 可编辑模块

- 水质指标（pH、水温、溶解氧作为一个整体）
- 视频监控
- 生物量估计与计数
- 3D 池塘模型
- 智能体
- 6 个外部系统入口（作为一个整体移动和缩放）

内部文字、按钮、图表和输入框不再单独捕获，避免排版时误选。

## 编辑方法

- 按住上述任意模块直接拖动：第一次按下即自动选中并移动。
- 也可以拖动选框上方蓝色标签：移动已选元素。
- 拖动选框四边或四角：改变宽度和高度。
- 右侧属性栏：修改文字内容、字号、字重、颜色、行高、背景、圆角、内外边距、层级和透明度。
- 方向按钮：每次移动 1px，用于精细对齐。
- 预览交互：关闭编辑拦截，测试正式页面按钮、弹窗和三维组件。
- 弹窗编辑：先进入“预览交互”打开弹窗，再点“返回编辑”，即可逐项选择和调整弹窗里的文字、按钮、表格和输入框。
- 保存设计：写入 `layout-prototype/layout.json`。

Canvas/WebGL 内部图形（ECharts、视频、Three.js 三维模型）无法逐个选择内部绘制对象，但其整个组件容器可以拖动和缩放。

保存后告诉 Codex“按照可视化编辑器保存的设计修改正式前端”，Codex 会读取 `layout.json`，将视觉覆盖转换为正式 Vue/CSS 源码。
